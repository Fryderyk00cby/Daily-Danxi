# 树洞日刊 · DanXi Daily

在自己的 Windows 电脑上阅读复旦树洞热议帖。用浏览器一键获取帖子、自定义筛选和热度排序，查看匿名昵称、标签、正文与跟帖。

这是一个独立的本地阅读工具，接口实现参考了 DanXi 客户端。需要你拥有可正常使用的树洞账号；使用 WebVPN 时，还需要能登录复旦 WebVPN。它不会代替账号注册、学校认证或论坛权限验证。

## 功能

- **生成日报**：获取指定时间范围内的新帖，展示回复数、浏览数和收藏数。
- **自定义筛选**：设置时间、抓取页数、展示条数、最低回复数，以及包含或排除的关键词。
- **灵活排序**：综合热度、回复最多、浏览最多、最新发布；热度权重可以修改。
- **阅读讨论**：显示接口返回的匿名昵称和标签，打开详情阅读正文，分页加载跟帖。
- **停止与继续**：停止查找后保留已获取的帖子，可以从上次分页位置继续。
- **本机登录缓存**：树洞令牌和 WebVPN 会话使用 Windows DPAPI 加密保存，失效后重新登录。
- **离线演示**：用虚构数据体验界面，无需登录论坛。

## 首次安装

### 1. 准备环境

需要：

- Windows 电脑。
- Python **3.10 或以上**，安装时启用 `Add Python to PATH`，或安装了 Python Launcher（`py` 命令）。
- 已安装 Microsoft Edge 或 Google Chrome。
- 可以访问依赖下载源的网络；实际抓取还需要论坛或 WebVPN 可连通。

前端直接使用 HTML、CSS、JavaScript，不需要 Node.js、npm，也不需要编译网页。

### 2. 下载并解压整个项目

从 GitHub 下载 ZIP 后先解压到一个可写的文件夹，或使用 Git 克隆仓库。不要只下载 EXE，也不要直接在 ZIP 内运行。

### 3. 双击 `setup.cmd`

安装窗口会自动：

1. 检测 Python 版本。
2. 在项目内创建 `.venv` 虚拟环境。
3. 根据 `requirements.txt` 安装 Playwright 和 cryptography。
4. 生成或更新 `DanXiDaily.exe` 启动器。

看到 `Ready. Double-click DanXiDaily.exe to start.` 后即完成。首次安装需要联网；日常使用不必重复安装。

安装程序使用电脑上已有的 Edge / Chrome，不需要另外执行 `playwright install`。

## 日常启动与退出

**双击项目根目录的 `DanXiDaily.exe`**，浏览器会自动打开树洞日刊，不显示命令行窗口。也可以双击 `open_daily.cmd`。

- EXE 是启动器，**不是包含所有依赖的单文件软件**。请将它保留在项目文件夹里；可以给它创建桌面快捷方式。
- 不要直接打开 `web/index.html`，网页需要本地 Python 服务。
- 页面地址为 `http://127.0.0.1:随机端口/`，每次启动可能变化。请使用启动入口，不要收藏旧端口地址。
- 用完点击左下角 **“退出本地服务”**。仅关闭浏览器标签页不会停止后台服务。
- 更新源码前先退出旧服务，再重新启动。依赖变更、移动 Python 环境或把项目复制到另一台电脑后，重新运行 `setup.cmd`。

## 第一次生成日报

1. 打开页面，保持 **“通过复旦 WebVPN 访问”** 勾选。
2. 点击 **“一键生成日报”**。
3. 如果 WebVPN 缓存不存在或失效，会打开独立的浏览器窗口。请在学校官方页面完成统一身份认证，并保持该窗口打开；任务结束后工具会关闭它。
4. 如果树洞令牌不存在或失效，日刊页面会弹出登录框。这里输入的是 **树洞注册邮箱和独立密码**，与学校统一认证不同。
5. 已获取的帖子会陆续显示。等待完成，或手动停止。

两种会话有效时都可以自动恢复，不必每次输入账号。学校或论坛可能主动让会话过期，不能保证永久免登录。

如果当前网络本身能直连论坛，可以取消 WebVPN 选项。仅登录浏览器中的学校 WebVPN，并不会自动让其他软件获得校园网访问能力；本工具通过自己的 WebVPN 会话转发请求。

想先看效果，可以点击 **“看看演示”**。演示帖子、昵称、标签和回复都是虚构的。

## 筛选与排序

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| 最近小时数 | 24 | 获取最近 1–168 小时**新发布**的帖子 |
| 最多抓取页 | 40 | 每页请求 10 条，单次最多 1–100 页 |
| 展示条数 | 20 | 筛选后最多展示 1–100 条 |
| 最低回复数 | 0 | 隐藏回复数低于该值的帖子 |
| 包含关键词 | 空 | 用中英文逗号分隔，任意一个命中即可保留 |
| 排除关键词 | 空 | 用中英文逗号分隔，任意一个命中即隐藏 |
| 排序方式 | 综合热度 | 还可选择回复最多、浏览最多、最新发布 |
| 回复 / 收藏 / 浏览权重 | 5 / 3 / 1 | 每项为 0–100 的整数 |

关键词匹配范围是 **首层正文与帖子标签**，英文不区分大小写；不会遍历全部回复来搜索，也不执行正则表达式。

综合热度的计算方式：

```text
热度 = 回复权重 × 回复数
     + 收藏权重 × 收藏数
     + 浏览权重 × ln(浏览数 + 1)
```

点 **“应用筛选并保存”**，会即时重新筛选已经获取的帖子，并将偏好保存在本机。修改时间范围、抓取页数或访问方式后，需要再次生成，才会影响网络请求。

这里的热度是自定义排序，**不是官方热榜**。互动数量是接口返回的累计值，不是过去一天的增量。达到页数上限时，结果只代表已获取的帖子，不代表完整时间范围。

## 停止、继续与重新生成

- **停止查找**：等当前请求结束后停止分页，保留已获取的内容。网络等待或认证页面跳转期间，停止可能需要一些时间。
- **继续查找**：从保留的位置继续，沿用暂停时的时间范围和抓取设置；每次继续最多再获取所设页数。
- **一键生成日报**：开始一次新的查找，替换当前结果。

查找进度和帖子保存在当前服务内存中。退出服务后不会保存进度，重新启动需要再次生成。

## 正文、昵称、标签和跟帖

卡片显示楼主的匿名昵称、标签、正文片段和互动计数。点击 **“阅读正文与跟帖”** 打开详情：

- 展示首层完整文本，并自动请求第一批跟帖。
- 点 **“加载更多跟帖”** 每次读取 10 层，直到接口返回末尾。
- 按楼层 ID 去重，已展示的首层不会重复插入。
- 回复显示匿名昵称、楼层 ID、接口返回的时间和正文；删除楼层显示占位文字。
- 未返回昵称或标签时，会显示相应说明，不推测用户身份。

当前按纯文本阅读，Markdown、图片、表情和公式不做完整渲染。需要原版排版或其他互动功能时，可在旦夕客户端中搜索洞号。

## 隐私与本地文件

本工具不保存账号密码，不读取旦夕客户端或日常浏览器里的登录信息。输入的密码仅用于对应服务的认证；工具自身没有云端数据库。

| 位置 | 内容 | 是否加密 |
| --- | --- | --- |
| `local_data/session.dpapi` | 树洞访问令牌、刷新令牌 | Windows DPAPI |
| `local_data/webvpn.dpapi` | WebVPN 网关 Cookie | Windows DPAPI |
| `local_data/reader_settings.json` | 筛选偏好 | 否 |
| `local_data/python_path.txt` | 启动器使用的本机 Python 路径 | 否 |
| `.venv/` | 本项目的 Python 环境与依赖 | 否，不存放登录凭据 |

DPAPI 缓存绑定当前 Windows 用户。仅保存 WebVPN 网关 Cookie，不保存学校身份认证站点 Cookie。会话无法恢复时需要重新登录。

网页版本的帖子和回复通常只在服务内存中；旧版本生成的 `local_data/daily.html` 等文件仍可能含论坛正文，升级不会自动删除这些已有内容。

点 **“清除登录缓存”** 可同时清除两种会话，不会删除筛选设置。退出服务后删除 `local_data/`，可移除该目录中的所有本工具数据；之后运行 `setup.cmd` 重新配置即可。

`local_data/`、`.venv/`、Python 缓存和 `.dpapi` 文件已加入 `.gitignore`。如果文件曾经被 Git 跟踪，新增忽略规则不会移除历史记录；分享前可用 `git ls-files` 检查，不要手动强制添加这些文件。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 不知道如何启动 | 首次双击 `setup.cmd`；安装后双击 `DanXiDaily.exe` |
| 提示找不到 Python | 安装 Python 3.10+ 并启用 PATH 或 Python Launcher，再运行安装脚本 |
| 安装依赖失败 | 检查安装窗口里的错误和网络连接，修复后重新运行 `setup.cmd` |
| EXE 提示缺少文件或 Python | 不要单独移动 EXE；在完整项目目录重新运行 `setup.cmd` |
| 无法启动认证浏览器 | 确认已安装 Edge 或 Chrome；企业策略也可能限制自动化浏览器启动 |
| WebVPN 已登录，仍要求树洞密码 | 两套账号不同；网页登录框需要树洞注册邮箱与独立密码 |
| HTTP 401 | 查看具体提示，检查对应账号或令牌；可清除登录缓存后重新登录 |
| HTTP 400 / 422 | 参数或接口校验失败；记录页面中的参数错误提示以便排查 |
| HTTP 403 / 429 | 可能是权限限制或请求频率限制，检查账号状态或稍后重试 |
| SSL EOF、连接断开或超时 | 尝试启用 WebVPN，确认能访问学校认证页面；工具不会关闭证书验证 |
| 筛选后没有帖子 | 清空关键词、降低最低回复数，或扩大时间范围后重新生成 |
| 生成内容比预期少 | 检查是否达到页数上限、是否手动停止，以及账号能访问的板块范围 |
| 页面显示本地服务未连接 / 无权访问 | 退出旧页面，使用 EXE 重新打开；不要使用过期地址或直接打开 HTML |

排查启动问题时，可以在项目文件夹的终端中运行：

```powershell
.\.venv\Scripts\python.exe main.py
```

## 项目结构

```text
danxi_summarize/
├─ README.md                   使用说明
├─ requirements.txt            Python 依赖
├─ setup.cmd                   首次安装入口
├─ DanXiDaily.exe               Windows 无控制台启动器
├─ open_daily.cmd               备用启动入口
├─ main.py                     Python 启动入口
├─ app/
│  ├─ server.py                本地 HTTP 服务、任务与登录流程
│  ├─ forum.py                 论坛接口、时间分页、令牌加密
│  ├─ webvpn.py                WebVPN 认证、转发与缓存
│  └─ ranking.py               筛选、热度计算与跟帖分页
├─ web/
│  ├─ index.html               页面结构
│  ├─ style.css                页面样式
│  └─ app.js                   页面交互
├─ scripts/
│  ├─ install.ps1              创建虚拟环境与安装依赖
│  └─ build_launcher.ps1       生成通用 Windows 启动器
├─ docs/DEVELOPMENT.md          代码维护说明
├─ local_data/                 本机数据，Git 忽略
└─ .venv/                      安装后创建，Git 忽略
```

开发时参考的 `DanXi/` 和 `danxi_exe/` 目录不属于运行依赖，已忽略提交；新用户无需下载，可自行移除本机副本。

## 当前范围

目前提供本机手动阅读，不包含定时任务、外部推送、AI 总结、发帖或评论功能。获取范围按**发布时间**计算，老帖最近被回复不会因此纳入新帖日报。论坛接口、账号权限和学校网络策略变化可能影响可用性。

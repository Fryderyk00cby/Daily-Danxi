# 树洞本地日报

## 网页界面（推荐）

双击项目根目录的 **`DanXiDaily.exe`**，自动打开浏览器中的“树洞日刊”，不显示命令行。可右键它创建桌面快捷方式。`open_daily.cmd` 也会启动同一个 EXE；`.pyw` 和 VBS 启动器已删除。EXE 是本机启动器，仍需要此文件夹中的 Python 源码、网页资源和已有的 Python 环境，请勿单独移动 EXE（可以创建快捷方式）。如果换了 Python 安装路径，可运行 `build_launcher.ps1` 重建启动器。

前端为 `web/index.html`、`web/style.css`、`web/app.js`，无需 Node.js 或 npm。Python 后端 `local_web.py` 只监听本机 `127.0.0.1`，使用随机端口与每次启动的访问密钥，不发布到互联网。请从启动入口进入页面，不要直接双击 HTML 文件。

点击“一键生成日报”后在页面阅读，树洞登录框也在网页中；WebVPN 失效时仍会打开官方认证浏览器窗口。页面不会保存密码。使用结束可点击左下角“退出本地服务”；只关闭浏览器标签页不会停止后台服务。原 Python 桌面界面 `daily_gui.py` 保留作备用。

左侧支持时间窗口、抓取页数、展示条数、最低回复数、包含/排除关键词和排序方式；关键词用逗号分隔，“包含”任意命中即可，“排除”任意命中即隐藏。筛选范围为首层正文与标签。综合热度可调整回复、收藏和浏览对数的权重。点“应用筛选并保存设置”即时更新已抓取结果；改变时间窗口和页数后需重新生成。设置保存到 `local_data/reader_settings.json`。

每张卡片展示帖子标签。“查看正文与跟帖”打开讨论详情，自动加载首批楼层，可点击“加载更多跟帖”每次读取 10 层，直到接口返回末尾；已展示首层按楼层 ID 去重。展示匿名昵称、楼层 ID、时间和正文，删除楼层显示占位文字。跟帖按需联网读取，不批量抓取全部帖子的回复，也不持久保存。演示模式包含虚构标签和跟帖。

“查看演示”无需联网。“清除登录缓存”同时清除树洞与 WebVPN 会话。生成时后台运行，失效的认证会打开对应登录窗口。

卡片和详情首层都展示接口返回的匿名昵称，回复楼层也显示各自昵称。接口没有提供时明确显示“接口未提供昵称”，不会推测真实姓名。

生成过程中可以点击“停止查找”，等待当前网络请求结束后停止，保留并展示已经获取的帖子。点击“继续查找”从上次分页位置继续，沿用暂停时的时间范围和抓取设置；每次继续最多额外获取所设置的页数。点击“一键生成日报”则从头重新查找。暂停状态仅保留在当前服务内，退出服务后不保留查找进度。

## 命令行入口（可选）

`open_daily.cmd` 现在启动网页界面。原来的命令行版本可以通过 `python local_daily.py --webvpn` 运行。需要 Windows、Python 3.10 以上及 Edge 或 Chrome；缺少依赖时运行 `python -m pip install -r requirements-local.txt`。

WebVPN 浏览器使用独立临时会话，不读取日常浏览器或旦夕客户端的凭据。首次登录后，仅将 WebVPN 网关 Cookie 用 Windows DPAPI 加密保存到 `local_data/webvpn.dpapi`，绑定当前 Windows 用户；不保存统一认证密码或认证站点 Cookie。下次先恢复并检测会话，有效时跳过登录，失效时清除缓存并打开登录页面。服务器可能让会话过期，因此不能保证永久免登录。全程保留 HTTPS 证书验证。

如登录返回 401，控制台现在会标明失败接口。`auth.fduhole.com/api/login` 失败表示旦夕账号登录被拒绝：请输入树洞注册邮箱和独立密码，而不是学号和统一认证密码；登录框提供官方密码重置入口。若登录成功后论坛接口仍返回 401，程序最多尝试一次重新登录并清除无效缓存，不会无限重试。

如果出现 `SSL: UNEXPECTED_EOF_WHILE_READING`，表示直连连接被提前断开。本机已复现；客户端能打开且开启 WebVPN 时，应使用以上入口。校内直连可使用 `python local_daily.py`，不加 `--webvpn`。

双击 `open_demo.cmd` 可以先看虚构数据演示，无需登录或联网。

## 首版范围

- 最近 24 小时**新发布**的帖子，按自定义热度排序展示前 20 条。老帖当天重新活跃暂不计入。
- 热度为 `回复数×5 + 收藏数×3 + ln(浏览数+1)`，不是官方热榜，也不是过去一天互动的增量。
- 默认最多获取 20 页，每页请求 10 条（与客户端一致）；页面会注明是否扫描到时间边界。仅覆盖账号有权访问且接口返回的帖子。
- 展示首层原始文本、洞号和互动计数。Markdown、图片和公式暂不渲染；可在旦夕中搜索洞号查看完整讨论。
- 日报保存在 `local_data/daily.html`，再次运行会更新。没有定时任务或外部推送。

## 登录和本地数据

密码只用于登录请求，不保存。访问令牌和刷新令牌使用 Windows DPAPI 加密保存到 `local_data/session.dpapi`，绑定当前 Windows 用户。后续自动刷新，失效时重新显示登录窗口。不会读取现有客户端的凭据。

运行 `python local_daily.py --logout` 可删除本地树洞令牌和 WebVPN 会话。日报包含论坛正文，保存在本机，不会发送到其他服务；删除 `local_data` 可移除本工具保存的数据。

## 参数

```powershell
python local_daily.py --hours 48 --max-pages 40
python local_daily.py --demo --no-open
```

接口依据本地 DanXi 源码 `lib/repository/forum/forum_repository.dart` 实现。未使用真实账号完成在线验证；若接口拒绝访问或需要额外验证，会显示错误，此时需在旦夕客户端确认账号状态。
